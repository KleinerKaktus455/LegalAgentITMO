# Тест-кейсы: мультиагентная система юриста

## Цель
Проверить корректность работы ключевых компонентов системы: нормализации данных, поиска аналогов, формирования ответа, UI-представления и форматирования.

## Типы тестов
- `unit` — изолированная проверка функции/класса без внешних зависимостей.
- `integration` — проверка взаимодействия нескольких компонентов (SQLite-хранилище + ранжирование).
- `e2e` — проверка полного сценария через CLI/UI (требует данных и, возможно, LLM-ключа).

## Окружение
- Python 3.11+
- pytest 9.0+
- Зависимости из `legal_multiagent/requirements.txt`
- SQLite используется in-memory или временный файл для изолированных тестов.

## TC-01: Парсинг статьи уголовного кодекса
- **Модуль:** `legal_multiagent.etl.fields.parse_article`
- **Тип:** unit
- **Предусловия:** нет
- **Шаги:**
  1. Вызвать `parse_article("Статья 158 Часть 2 п. в")`.
  2. Проверить поля `article`, `part`, `point`, `canonical`.
- **Ожидаемый результат:** `article == "158"`, `part == "2"`, `canonical` начинается с `"158"`.
- **Критерий приемки:** статья, часть и пункт извлекаются корректно.

## TC-03: Нормализация строки parquet

- **Предусловия:** подготовлена строка parquet с `id`, `text_1`, `text_2`, `text_3`.

## TC-04: Расстояние Жаккара для фабул
- **Модуль:** `legal_multiagent.etl.fields.overlap_score`
- **Тип:** unit
- **Предусловия:** нет
- **Шаги:**
  1. Вызвать `overlap_score("взыскание налоговой недоимки", "налоговая недоимка взыскание")`.
  2. Вызвать `overlap_score("взыскание налоговой недоимки", "преступление по статье 105")`.
  3. Проверить, что первый score больше второго и лежит в `[0, 1]`.

- **Критерий приемки:** функция возвращает значение 0–1 и корректно ранжирует похожесть.

## TC-05: Поиск аналогов и нормализация score в [0, 1]
- **Модуль:** `legal_multiagent.store.sqlite_store.CaseStore.search_analogs`
- **Тип:** integration
- **Предусловия:** создано временное хранилище с несколькими тестовыми делами.
- **Шаги:**
  1. Добавить 3 дела: одно с той же статьёй и регионом, одно с той же статьёй, одно без совпадений.
  2. Вызвать `search_analogs` с фильтрами.
  3. Проверить, что все `score` в диапазоне `[0, 1]`, топ имеет `score == 1.0`, результаты отсортированы по убыванию.
- **Ожидаемый результат:** нормализация работает, ранжирование сохранено.
- **Критерий приемки:** значения score ∈ [0, 1], топ = 1.0.

## TC-10: Полный цикл агента без LLM (stub)
- **Модуль:** `legal_multiagent.graph.run_agent`

- **Предусловия:** создан пустой или заполненный индекс, LLM не вызывается (или замокан).

- **Критерий приемки:** граф завершается без исключений.
